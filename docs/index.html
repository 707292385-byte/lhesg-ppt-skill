lhesg-ppt 技能

把技能装到本机的 WorkBuddy 客户端，用于制作 lhesg 风格演示文稿。

一键安装到 WorkBuddy

点击后浏览器会询问是否打开 WorkBuddy，选择「打开」；接着客户端弹出安装确认框，点确认即完成安装。

workbuddy://codebuddy-ide/skill/install?skillname=lhesg-ppt&channelType=link&downloadurl=…

也可以在客户端里手动上传

  1. 下载 技能包 lhesg-ppt-skill-20261010.zip（约 3.9 MB）
  2. 打开 WorkBuddy，左侧进入「技能」→「添加技能」→「上传技能」
  3. 选中刚下载的 zip，等待提示安装完成

使用前的一次性准备

技能依赖 python-pptx 与 Pillow，首次使用时装一次：
~/.workbuddy/binaries/python/envs/default/bin/pip install -r <技能目录>/requirements.txt

需要在已安装 WorkBuddy 的电脑上操作；手机或无客户端的电脑请走上面「手动上传」。 版本 v1.0.0 · 仓库
