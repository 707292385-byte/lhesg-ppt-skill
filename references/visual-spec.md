# 视觉识别规格

> 只写品牌识别与硬性几何。版式形态不在此列——版式是开放集，见 `layout-library.md`。

## 画布与基底

- 13.333 × 7.5 in（16:9），2 个母版，内容页统一用 layout2「标题和内容」（挂在带右上角 logo 的母版上）。
- 基底 `assets/base.pptx` 随 skill 分发，含母版、版式、主题，以及封面/结尾两张固定原型页。自定义基底用环境变量 `ESG_BASE` 覆盖。

## 字号（唯一标准）

| 类别 | 档位 | pt | 用途 |
|---|---|---|---|
| 正文类（≥12pt） | S_TITLE | 24 | 页标题（母版固定，勿改） |
| | S_H2 | 15 | 卡片/模块标题、形状内编号 |
| | S_BODY | 14 | **正文默认** |
| | S_DENSE | 12 | 正文下限，仅信息密集页 |
| | S_NUM / S_NUM_L | 30 / 34 | 关键数字 / 数据卡主数字 |
| 注释类（=9pt） | S_AUX | 9 | 口径说明、图注、单位、来源行 |

- 内容页合法档位只有 **9 / 12 / 14 / 15 / 24 / 30 / 34**；10–11pt 禁止使用。
- 封面标题 28pt、封面汇报人/日期 16pt、结尾主标题 44pt 属固定原型页的原生字号，不参与内容页档位。
- 字体：思源黑体 Heavy / Medium / Light；`set_font` 同时写 latin + ea + cs。

## 几何

- 左右边距 0.67 / 右至 12.66（内容宽 11.99）。
- 正文区 y ∈ [1.42, 6.80]；来源行 y=6.88（9pt）；装饰条 y≥7.2 勿侵入。
- 标题行右段（x>9.5 且 y<1.2）被右上角 logo 占用。
- 结论条：通栏、浅蓝底 + 左侧 0.06in 竖线，底边按内容自上排，不固定在页面底部。

## 固定页（封面 / 目录 / 结尾）

- **封面与结尾页**：整页沿用基底原型，只替换文字（标题、汇报人、日期、地址、联系人、电话），不做几何改动以外的自由发挥。封面不设副标题，需要补充信息写进标题次行。
- **目录页**：内容页标题样式 + 编号卡片列表，条目数量自适应。
- 特殊页同样接受 `font_lint.py` 与 `verify_deck.py` 校验。

## 交付前校验

1. `font_lint.py` 通过：正文 ≥12pt、注释 9pt、无非规范档位。
2. `verify_deck.py` 通过：layout2 挂接、母版元素继承、标题样式正确、无分节残留。
3. 渲染拼图目检：无溢出/截断/压线，相邻页不同构。
4. 全部数字可回溯，来源行与内容一致。
5. 标题全部为结论式表述。

**不校验项**：版式形态。任何形态只要守住识别元素、色板、字号、安全区即可。
