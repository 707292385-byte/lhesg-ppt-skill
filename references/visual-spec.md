# lhesg 风格 PPT 视觉识别规格（本 skill 基线，实测自内置基底）

## 基底结构

- 画布：13.333 × 7.5 in（16:9）；基底 2 个母版；**内容页全用 layout2「标题和内容」**（属带右上角 logo 的母版 master1）。
- 基底：`assets/base.pptx` 随 skill 分发（含封面/结尾页原型 slide1 / slide28，已预清分节），自包含；自定义基底用环境变量 `ESG_BASE` 覆盖。

## 字号体系（两类两档，无例外）

| 类别 | 档位 | pt | 用途 |
|---|---|---|---|
| 正文类（≥12pt） | S_TITLE | 24 | 页标题（母版固定，勿改） |
| | S_H2 | 15 | 卡片/模块标题（Medium + Bold）、形状内编号/标签 |
| | S_BODY | 14 | **正文默认** |
| | S_DENSE | 12 | 正文下限，仅信息密集页（表格内容、对比卡） |
| | S_NUM / S_NUM_L | 30 / 34 | 关键数字 / 数据卡主数字 |
| 注释类（=9pt） | S_AUX | 9 | 口径说明、图注、单位、页脚来源行 |

**10–11pt 是无主档位，禁止使用**；合法档位只有 9 / 12 / 14 / 15 / 24 / 30 / 34。`set_font` 拦截 <9pt，`font_lint.py` 拦 10–11pt 与其它非档位值。

字体：思源黑体 Heavy / Medium / Light；set_font 需同时写 latin+ea+cs。

## 版面几何

- 左右边距 0.67 / 右至 12.66（CONTENT_W = 11.99）。
- 正文区 y: 1.42 → 6.80；来源行 y=6.88（9pt）；装饰条 y≥7.2 勿侵入。
- 标题行右段（x>9.5, y<1.2）被右上角 logo 占用。
- 卡片圆角 radius 0.045（大卡）～0.16（结论条）；结论条统一"浅蓝底 + 左竖线 0.06 + 前半句加粗"。
- 竖强调线宽 0.045（列表分隔）或 0.06（结论条）。

## 特殊页几何（kit 内置 cover / toc / end，克隆式实现）

**封面 / 结尾页 = 整页克隆基底原型页（slide1 / slide28），仅替换文字。**
克隆机制 `_clone_template_slide()`：读基底页 XML + rels → 图片关系重映射（两段式替换防 rId 撞号）
→ 替换新页的 p:bg 与 spTree 全部内容 → 按 `{旧文本(去空白): 新文本}` 改字（`_set_shape_text`
沿用原 run 的字体格式，`\n` 拆多段）。不要再用"自绘形状拼特殊页"的方式——自由发挥必然与原型有出入。

- **封面（克隆 slide1）**：克隆后仅两处几何调整——箭头条图片加高 1.23→**1.89in**（中心 y=2.495
  不变，纯渐变色带可无损纵向拉伸），容纳两行 28pt 标题；标题框改为 7.09,1.70,5.90×1.60、
  bodyPr anchor="ctr"。标题字号 28pt（S_COVER，基底原值）、颜色沿用基底默认深色；
  汇报人/时间行 16pt（基底原值）。文字替换键：`此外添加标题` / `XXX` / `20XX年XX月XX日`。
  **封面不设副标题**——基底原页没有该元素，额外信息写进标题次行，不要另加文本框（`cover()` 已无 subtitle 参数）。
  汇报人/日期值框已由 `cover()` 放宽到 2.24in（原 1.13in 装不下 5 个汉字）并设 `wrap="none"`；结尾页联系人值框同理放宽到组右边界 2.23in。
- **结尾（克隆 slide28）**：零几何改动，完全基底原样——深蓝底 1C589E（0,0,13.33×6.14）+
  装饰弧面（12857 顶点 freeform，1F5FAD）+ 44pt（S_END）白色 Heavy 主标题 + 公众号二维码 +
  12pt 标签 + 地址行 14pt + 联系人块 14pt 加粗 + 白区蓝色 logo。挂 master2（无右上角 logo）。
  文字替换键：`谢谢关注！` / `XXX`（联系人值）/ `88888888888`（电话值）/ 以"地址"开头的整块。
- **目录**：layout2 标题样式（蓝块+灰块+主蓝标题）+ 编号卡片列表（chip 0.5×0.5 主蓝 15pt 白字，
  浅蓝/白底交替，条目 15pt，右侧 9pt 注释），条目数量自适应。
- **verify_deck**：特殊页（版式名为「标题幻灯片」/「空白」，或挂在非内容母版上）不要求标题占位符。

## 校验清单（交付前逐项过）

1. `font_lint.py` 通过：正文 ≥12pt、注释 9pt、无非规范档位。
2. `verify_deck.py` 通过：layout2 挂接、母版 logo/装饰条、标题样式 044AC0/24pt/思源黑体 Heavy。
3. 渲染拼图目检：无溢出/截断/压线，相邻页版式不同构。
4. 全部数字可回溯；来源行与内容一致。
5. 标题全部为结论式表述。

**不校验项**：版式形态。本 skill 只约束上表中的识别元素、色板、字号、安全区；版式属开放集，任何形态只要守住上述约束即可，不存在"必须使用某几种版式"的要求。
