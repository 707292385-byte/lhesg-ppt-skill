# 设计经验：lhesg 风格的判断依据

> 这里写的是**判断**，不是某一版 deck 的参数。任何一条都不指向具体某套成品；
> 拿它们去设计新页面时，版式仍要按当次内容重新决定。
> 字号与色板属硬性规范，见 `SKILL.md`；具体几何见 `visual-spec.md`。

## E1 一页一个论点，标题即结论

- **做法**：标题写判断，不写主题。双段式——前半句是要害判断（主蓝加粗），后半句补机理或范围（正文色常规字重），合计 ≤25 字。
- **为什么有效**：读者只读标题就能拿到全套论点；正文退为证据，而不是主旨。
- **怎么用**：先问"这页要读者记住哪一句"，把这句话压到 25 字内放最前。禁"XX 概述 / XX 介绍 / 现状分析"。
- **全页结论置顶**：标题之外若还需要一句总判断，紧贴标题下方通栏一条，**证据一律排在其下**。全页顺序固定为 标题 → 全页结论 → 证据 → 来源行。结论条为浅蓝底 + 左侧主蓝竖线，条内 14pt、前半句加粗。

## E2 信息分层，不要一个大框罗列

- **做法**：按四级层级组织——模块标题 15pt → 关键数字 30–34pt → 正文 14pt（密集页 12pt）→ 注释 9pt。同一语义单元拆成"标签行 + 内容行"。
- **为什么有效**：层级差制造可扫读性；碎片化让留白自然出现，避免一段话塞满半页。
- **怎么用**：先列本页语义单元（通常 3–5 个），每个至少拆成两个文本框。文本框数量偏少，通常意味着内容没分层。

## E3 不对称分栏 + 交替底色

- **做法**：左右分栏不等宽，比例按主次定，常用约 6:5 或 7:4。并列卡片用浅蓝底与白底+描边交替。
- **为什么有效**：等宽三列呆板；交替底色在无边框风格下自然分区，不依赖线条。
- **怎么用**：先定主次再定比例；相邻卡片换底色，而不是加分隔线。

## E4 深色只给结构，橙色只给负面

- **做法**：深蓝只用于表头、结论条、VS 圆等结构性元素，每页 ≤2 处；橙色严格限定在负面/警示事实，每页 ≤1 处。
- **为什么有效**：深色稀少才显重；橙色滥用就失去警示语义，也破坏品牌色纪律。
- **怎么用**：一页里数一遍深色块和橙色点，超了就减。

## E5 统一网格，但版式逐页变化

- **做法**：所有页共用同一套页边距与内容起点，翻页时元素不跳位；版式形态逐页不同，相邻两页不同构。
- **为什么有效**：稳定的网格消除翻页跳动；变化的形态避免"每页都一个样"。
- **怎么用**：新建页先落安全区锚点（见 `visual-spec.md`），再选本页的表达手法（见 `layout-library.md`）；选之前先看上一页用了什么。

## E6 表格与图标是稀缺手段

- **做法**：表格只用于多主体横向对照，整份 deck 控制在 1 张左右；图标 0.5–3 个/页，白图标垫蓝圆底、蓝图标直放。
- **为什么有效**：用多了会稀释层级；稀缺使用才让它们成为"这页不一样"的信号。
- **怎么用**：能用卡片并列讲清的就不上表格；图标只放卡片标题旁，不散落在正文里。

## E7 版式多样性（防止每次输出都相似）

判断标准不是"像不像以前那套"，而是"这套内容有没有被最合适的形态讲清楚"。执行三条：

1. **先规划后动手**：出页面清单时，每页同时写清用哪种表达手法（对照/时间轴/漏斗/矩阵/链条/层级/闸门/分界/双轨/象限/瀑布/表格），并说明为什么是它。用户确认后再构建。
2. **同套不重复**：同一份 deck 内，相邻两页不得同构；同一种手法整份最多用 2 次，且必须换一种内部结构（如两次用对照，一次左右分栏、一次上下分层）。
3. **跨套不复用**：不默认沿用上一套 deck 的页面结构。新任务从头做版式规划；旧 deck 只作为品牌识别和经验的来源，不作为版式模板。

手法清单、适用条件与结构写法见 `layout-library.md`。

## 一页自检

1. 标题是结论吗？只读标题能拿到论点吗？
2. 有全页结论的页，顺序是不是 标题 → 结论 → 证据 → 来源行？
3. 语义单元是否都拆成了"标签行 + 内容行"？层级是否跨 3–4 级？
4. 分栏是否主次有别？并列卡片是否靠底色区分而非分隔线？
5. 橙色 ≤1 处且指向负面？深色结构块 ≤2 处？
6. 这页的手法，和上一页、和上一套 deck 是否不同构？
7. 字号是否全部合规（正文 ≥12pt、注释 9pt、无非规范档位）？

## 禁忌

- 三列并列排满一页；连续两页以上同构；整份 deck 反复用同一种卡片矩阵。
- 有全页结论的页，把结论条落到页面底部。
- 一页只有 3–5 个大文本框，内容精简到只剩短语。
- 橙色当点缀色；自造色板外的高饱和色。
- 正文低于 12pt，或出现 10–11pt。
- 把写作指导、版式说明、对使用者的交代写进页面；结论条里加"本页结论："这类栏目标签。
- 直接套用旧 deck 的页面结构，只换文案。
